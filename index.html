How it works

The public API runs on Render's free plan and never calls the model directly. Messages go into a Postgres queue; a worker picks them up the moment they arrive, answers with Claude and writes the reply back. No open ports, no tunnel, and the API can always fall back to quick answers.

Grounded answers

Hybrid search (Postgres full-text plus local embeddings) over the case studies, with the visitor's current page ranked first. Answers cite their source.

Exactly once

Webhook replays, double clicks and retries are absorbed by unique keys: one reply per message, one booking per slot, one alert per handoff.

One script tag

The widget lives in a shadow DOM, adapts to the page it's on, goes full screen on phones and says when it's waking up.

Live on every demo page

Each page tells the assistant which project it's on, so the greeting and the search fit the page. Tap one to try it there.
