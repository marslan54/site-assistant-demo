# AI Site Assistant: demo

Live page: https://marslan54.github.io/site-assistant-demo/

An AI chatbot that answers from real case studies with sources, qualifies leads and hands chats to a person in Slack. The page embeds the live assistant, so you can talk to it. Watch the walkthrough: [site-assistant-demo.mp4](site-assistant-demo.mp4).

This repo holds only the demo page and recorded chats. The source is private.
